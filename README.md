# 英単語カード

スマホのブラウザで使う、自分専用の英単語暗記アプリ。設計は [SPEC.md](SPEC.md)。

## 使い方
1. 左上の ⚙（データ管理）で Excel / CSV を取り込む（形式は [sample/sample-words.csv](sample/sample-words.csv) を参照）
2. 下のタブで 一覧／カード／四択／まとめ を切り替える。まとめでは今日の復習（忘却曲線）・学習の記録・記憶度の分布・四択の結果を見られ、「カードで復習する」で今日の復習の単語だけのカードが始まる
3. 右上の ≡ で絞り込む（3機能共通）
4. ときどき ⚙ →「バックアップ」で学習記録を書き出す

## ファイル構成
| ファイル | 役割 |
|---|---|
| `js/store.js` | 辞書・学習状態・学習ログの保存 |
| `js/importer.js` | Excel / CSV の取り込み |
| `js/filter.js` | 絞り込み（≡） |
| `js/list.js` / `card.js` / `quiz.js` | 一覧／カード／四択 |
| `js/manage.js` | データ管理 |
| `js/app.js` | 画面の切り替えと起動 |

## ホーム画面に追加・オフライン
- 公開したページをスマホで開き、共有メニューから「ホーム画面に追加」するとアプリのように使える
- 一度開けば、通信できないときも端末に保存した部品で動く（`sw.js`）
- 部品のファイルを増やしたときは、`sw.js` の `APP_FILES` に足し、`CACHE` の番号を上げる

## 効果音
- `sound/` の音を `js/sound.js` が鳴らす。shu＝画面の切り替え、maru／batsu＝四択の正解／不正解、pon＝絞り込み・設定・一覧、kachi＝カード・四択のボタン
- ⚙ →「表示」でオン／オフを切り替えられる

## 注意
- 学習記録はブラウザ内（localStorage）にだけ保存される。ブラウザのデータを消すと消える
- `word/TSL_単語リスト.csv`（とリポジトリ直下の `words.xlsx`）は起動時に自動で取り込む。単語を足したらこのファイルに行を足して push すれば、どの端末でも次に開いたとき反映される。公開リポジトリなので誰でも見られる
- 自動で読み込むファイルを変えるときは `js/app.js` の `AUTO_FILES` を直す
